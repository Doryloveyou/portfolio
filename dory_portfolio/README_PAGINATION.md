# Dory Portfolio + SpeechTrack Pagination Version

這版已改成頁面導覽，不使用彈窗。

## 使用方式

1. 打開最外層 `index.html`
2. 到 Works 區塊
3. 點 j5 SpeechTrack 的 `View Case`
4. 會進入 `speechtrack_project/index.html`
5. 專案頁底部有 Back / Previous / Next pagination

## 主要修改

- 首頁 View Case 改為連結：`speechtrack_project/index.html`
- 移除首頁 modal dialog
- 移除 JS 裡的 modal 控制
- 專案頁新增 `.case-pagination`
